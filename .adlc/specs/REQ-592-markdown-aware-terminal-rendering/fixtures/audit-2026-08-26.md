### Areas Verified as Strong

| Surface | Finding |
|---------|---------|
| **Socket auth** | Peer-credential check via `getpeereid`/`SO_PEERCRED`, not TOCTOU-spoofable. Socket file `0600`, parent dir `0700`. Pid collected for ancestry. Refusals are content-free. |
| **Path jail** | `ToolContext::resolve` canonicalizes *then* checks `starts_with(root)`. Symlinks resolved to targets — a link escaping root is refused. Broken symlinks refused. No fallback to user-supplied string. Provenance minted from canonical path only. |
| **Shell tool** | `sh -c` under cwd jail, env scrub (name + credential-URL value), PATH floor, process-group leader, SIGKILL on timeout. Output capped. Unknown provenance → egress fail-closes when boundary configured. |
| **Egress choke point** | Single point for all remote calls. Provenance-based blocking, not string-scanning. Session taint backstop pins to local tier once any boundary/unknown provenance is seen. |
| **SSRF protection** | `AddressClass` blocks loopback, private, link-local, unique-local, unspecified. DNS resolution screened. Redirect hops re-checked. No private-fetch bypass. |
| **Redaction** | `Finding` has **no text field** — cannot quote the secret it matched. Confidence derived structurally, never self-reported. Over-cap payload → Block, never truncate-and-scan. |
| **Credentials** | Never in files, logs, errors, or telemetry. `auth_ref` (`keychain://…`) is the only thing in config. Daemon resolves at call time. Keychain backend is trait-injected; tests never touch real store. |
